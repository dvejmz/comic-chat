# Running Comic Chat on Linux

This modernised version of Comic Chat was built and tested to run on Windows 11. You will [need Wine](https://gitlab.winehq.org/wine/wine/-/wikis/Download) to run it on Linux, where it runs without issue.

The upstream Microsoft repo has a few bugs under Wine, which this fork has patched.

Once you have installed Wine, you can launch the application simply,

```
wine CChat.exe
```
